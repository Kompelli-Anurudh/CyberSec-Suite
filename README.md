# CyberSec Suite

A collection of cybersecurity tools built with web technologies.

🔗 [Live Demo](https://kompelli-anurudh.github.io/CyberSec-Suite/)

## Features

- **Password Checker**: Test password strength and generate secure passwords
- **Web Scraper**: Extract data from websites with customizable options
- **File Encryption**: Secure file encryption and decryption using AES-GCM
- **Malware Scanner**: Scan files for potential threats using YARA rules

## Live Demo

## Setup and Usage

1. Clone the repository:
   ```bash
   git clone https://github.com/Kompelli-Anurudh/CyberSec-Suite.git
   ```

2. Open the project:
   - Use a web server (like Live Server in VS Code) to serve the files
   - Or open index.html directly in a modern web browser
   - Or visit the live demo at https://kompelli-anurudh.github.io/CyberSec-Suite/

3. No additional dependencies required - the project uses vanilla JavaScript and browser APIs

## Browser Compatibility

- Chrome (recommended)
- Firefox
- Edge
- Safari

## Security Considerations

- File encryption uses AES-GCM for secure encryption
- Password handling is done client-side
- YARA rules scanning is simulated for demonstration
- No data is sent to external servers

## Deployment

This project is deployed using GitHub Pages. To deploy your own version:

1. Fork this repository
2. Go to your fork's Settings > Pages
3. Set the source branch to `main`
4. Set the folder to `/ (root)`
5. Your site will be published at `https://[your-username].github.io/CyberSec-Suite/`
